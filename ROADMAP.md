# 🗺️ Lexify Strategic Product Roadmap (2026–2027)

Lexify is an AI-powered language learning ecosystem combining a Telegram Mini App, Web Platform, and AI Assistant.

---

## 🚀 Phase 1: Core AI & Spaced Repetition Engine (Completed & Active)
- [x] **Telegram Mini App & Web Sync**: Unified user accounts via Telegram `initData` and Web JWT.
- [x] **Groq AI Vocabulary Engine**: Instant word explanations, CEFR level tagging (A1–C2), and native translations.
- [x] **Spaced Repetition System (SRS)**: Adaptive review scheduling based on user recall accuracy.
- [x] **IELTS Writing Evaluator**: Automated band score breakdown across Task Response, Coherence, Lexical Resource, and Grammar.
- [x] **Shadowing Tool**: YouTube caption playback and sentence-by-sentence shadowing practice.

---

## ⚡ Phase 2: Viral Growth, Audio & Gamification (Current Focus — Intensive Sprint)
- [x] **Viral Referral Engine**: Deep-linked `/start ref_123` referral links with custom invitation messages.
- [ ] **Web Speech Audio Engine**: 1-click native audio pronunciation for vocabulary in Web & Telegram.
- [ ] **SM-2 Algorithm Enhancement**: Upgraded Spaced Repetition algorithm calculating exact memory decay curves (`easiness_factor` & `interval`).
- [ ] **Streak Protection & Achievement Badges**: Gamified milestones (7-day streak, 100 mastered words, IELTS Scholar).
- [ ] **Social Share Cards**: Dynamic OG image generator for sharing quiz scores and essay band results on social media.

---

## 🌐 Phase 3: Ecosystem Expansion & Browser Integration (Next)
- [ ] **Lexify Web Clipper Extension**: Chrome & Firefox extension to look up and save any word directly from web articles.
- [ ] **PWA Offline Mode**: Full offline vocabulary library with IndexedDB caching and background sync when reconnected.
- [ ] **Community Pack Marketplace**: User-curated vocabulary lists with rating and one-click import.
- [ ] **IELTS Speaking AI Simulator**: Interactive voice-to-voice mock speaking tests with instant pronunciation and fluency feedback.

---

## 💼 Phase 4: Monetization & B2B School Portal
- [ ] **Lexify Premium Subscription**: Unlimited IELTS essay reviews, advanced AI tutor personas, and priority Groq inference.
- [ ] **Language School Dashboard**: Teacher portal to assign vocabulary lists and track student review streaks.
- [ ] **Public API**: Developer API for integrating Lexify vocabulary engine into third-party apps.
